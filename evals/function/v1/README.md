# Function Jac evaluation v1

This directory is generated by `scripts/build_function_eval.py`.

- `public/`: prompts and visible prefixes for model generation.
- `private/`: hidden tests and references for `scripts/eval_jac.py`. Never train on these files.
- `denylist_ids.txt`: reject these source IDs from every training export.
- `denylist_clusters.txt`: normalized Python AST clusters reserved by this eval.
- `clusters.jsonl`: representative and complete source-cluster membership.

The manifest status is `candidate_unvalidated` until all reference solutions pass the private tests under the pinned Jac toolchain.
