# cvt-l5-networking-bingo
Source Pseudo-Lab/PseudoTown (MIT) @fc784d5, api/. FARM L5: 4 ODMantic models -> nodes, 7 handlers ->
walker:pub, classmethod result dicts reported verbatim (Korean messages). Tests pin the faithful quirks
(re-subtracting MAGIC_NUM, gave_ids append keyed on user_id) which the request tells the agent to keep.
Persistence check: the board mutation must be visible to a later get (in-process and over HTTP).
Negatives: unattached board, mutated copy never written back, row/col swap, "fixed" gave_ids logic,
counter not persisted, attributes looked up for the wrong member.
