{\Large\bfseries Prompt Injection as Pipeline Architecture --- one-pager}\\[1pt]
{\small \file{scripts/gen/osp\_generate.py} + \file{osp\_luna\_generate.py} · \file{jac\_llm\_data} · Sept 2026 · full report: \file{docs/osp\_prompt\_injection\_report.pdf}}

\medskip
The OSP codegen pipeline \textbf{injects grounding material into the model's context at runtime} from files, distilled skills, verified demos, and the model's own compiler errors. Two injection sites:

\begin{minipage}[t]{0.52\textwidth}
\textbf{Site 1 --- import-time system-prompt surgery} (\file{osp\_luna\_generate.py:146--253}; inherited by \file{osp\_generate.py} via import, lines 88--91):
six operations transform a 3{,}740-char ``floor'' prompt into the 14{,}077-char payload every call rides on --- \textbf{73\% is injected, not written}.

\smallskip

\smallskip
\textbf{Site 2 --- error-conditioned hint injection (runtime).} Every gate failure re-prompts via \code{\_fix\_user()} (line 263): regex-scrape \code{undefined name 'X'} from the validator error and \textbf{inject a targeted repair hint} (\code{add edge X \{ \}} or use plain \code{-->}); retry $\le$ \code{fix\_tries}=2. Failures + broken code log to \file{osp\_dataset\_failures.jsonl} as repair-training material.
\end{minipage}\hfill
\begin{minipage}[t]{0.44\textwidth}
\textbf{Gates} (same bar as the composer-2.5 reference batch):\\
\code{extract\_jac} --- single \code{```jac} fence\\
\code{jac\_check} --- \code{jac check} $\rightarrow$ \code{jac run} $\rightarrow$ stdout must be non-empty (silent pass = regression)\\
\code{osp\_contract} --- 8 regex gates: docstring, no \code{Any}, typed \code{has}, \code{visit} after typed entry, \code{with entry}, \code{spawn}, self-referential ternary, no \code{\_\_main\_\_}, undefined visit names

\smallskip
\textbf{Measured:} holdout probe --- 10 problems failing the floor prompt 3$\times$ each went \textbf{0/10 $\rightarrow$ 3/10} with the injected context. Dataset: \textbf{7{,}275 records} (m3:free 4{,}970 · composer-2.5 1{,}308 · gpt-5.6-luna 975).

\smallskip
\textbf{Containment:} records persist only the \emph{raw} problem + final code in \code{messages} --- the injected context never enters the training transcript; provenance rides in metadata (\code{context\_bundle\_version} etc.).

\smallskip
\textbf{Risks:} file splices mean editing \file{OSP\_IDIOMIZE\_TASK.md} silently changes generation (provenance = one metadata field); layer order is precedence; the 3{,}500-char corpus cap truncates silently.

\smallskip
\textbf{Inspect live:} \code{osp prompt --stat} recomputes the table from the same module the pipeline uses; \code{osp prompt} dumps the full payload.
\end{minipage}
